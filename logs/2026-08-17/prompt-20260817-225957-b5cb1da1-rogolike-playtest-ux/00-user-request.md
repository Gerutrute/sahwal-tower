# 사용자 플레이테스트 피드백

1. 음악이 재생되지 않는다.
2. 지도에서 모든 지점을 선택할 수 있다. 각 막은 첫 번째 지점에서 시작하고, 완료한 노드의 `next`에 따라 다음 선택지 1~3개만 보여야 한다.
3. 승리 조건이 모호하고 플레이어가 판의 50% 이상을 점거해도 대국이 계속되어 루즈하다. 점유 우세를 명시하고 빠르게 종료되는 규칙이 필요하다.
4. 착수 시 확인 단계가 너무 많다. 카드 선택 후 합법 교차점을 한 번 누르면 착수가 확정되어야 하며, 부적·유물이 없으면 pre-move 확인을 강요하지 않아야 한다.
5. 카드 효과가 명시적이지 않고 시각적으로 구별되지 않는다.
6. 각 카드의 고유 효과를 전략적으로 활용해야 이길 수 있도록 전투·AI·UI를 설계하고 구현한다.

제약:
- 제품명 `RoGolike` 유지.
- dev 브랜치, commit/push 금지.
- strict TDD 및 AGENTS.md evidence lifecycle 준수.
- 사용자가 제공한 방향은 인간 게임 디자인 결정으로 기록한다.
