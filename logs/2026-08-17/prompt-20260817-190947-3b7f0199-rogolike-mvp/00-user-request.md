## 현재까지 사용자가 명시적으로 확정한 게임 디자인

- 제품 표시명: `RoGolike` (대소문자 정확히 유지)
- 최신 docs 0.2.3의 바둑·로그라이크 방향 사용
- 콘텐츠 ID: STONE-001~006, ITEM-001~005, RELIC-001/002/003/005/007/009/010/013, ENEMY-001~003
- 시작 덱: 일반석×6, 척후석×1, 수호석×1, 희생석×1, 장군석×1
- 시작 기풍 선택은 MVP에서 제외
- 음악 네 곡은 사용자가 직접 생성했고 공개 배포 가능
- 화면별 추천 음악 배치 승인, 일반 적 부활 시 bosstheme으로 전환
- EVENT-001~003 사용
- 상점 새로고침 제외
- 덤은 구현 후 seeded 색 반전 시뮬레이션 결과를 보고 제안

## 아직 사람 승인으로 간주하지 않는 AI 초안

- 부활 특성/전용 착수/2막 보스 세부 수치
- 경제·도장 고정값
- 효과 큐·생성 카드 안전 상한
- 지도 생성 가중치와 상점 접근 규칙
- 실제 청음으로 정할 곡별 gain/loop/crossfade 값

이 미결 수치는 주입 가능한 설정과 초안 fixture로만 구현하고, 사람 승인 전 제품 확정값으로 둔갑시키지 않는다.
