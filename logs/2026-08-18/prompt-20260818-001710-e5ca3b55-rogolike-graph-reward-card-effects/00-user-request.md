# 사용자 요청

직전 Hermes 제안안을 승인하고 구현을 진행한다.

## 승인된 변경

1. 지도 UI를 버튼 목록이 아닌 연결선이 보이는 세로형 그래프 노드로 변경한다.
   - 아래에서 위로 진행
   - 완료/현재 선택 가능/잠김 상태 구별
   - 실제 `next` 연결선 표시
   - 현재 노드에서 연결된 다음 선택지 1~3개만 활성화
2. 보상 카드에 상세 효과 정보를 제공한다.
   - 데스크톱 hover와 keyboard focus
   - 모바일 첫 tap으로 상세 펼침
   - 상세 안의 명시적 선택 버튼으로 보상 확정
   - 효과 요약, 발동 조건, 실제 효과, 전략, 추천 연계, 현재 보유 수량 표시
3. 시작 덱을 10장으로 유지하면서 일반석 5장 + 척후석/장군석/기병석/수호석/희생석 각 1장으로 변경한다.
4. 척후석: 착수 후 덱 위 3장 확인, 1장을 손패로 가져오고 손패 1장을 되돌리며 나머지 순서를 정한다.
5. 장군석: 해당 착수로 포획하면 기존 5냥 보상과 함께 카드 1장 추가 드로우(패 한도 적용).
6. 기병석: 직전 내 착수가 포획이었을 때 손패 진입 시 덱 위 2장 중 1장을 가져오고 손패 1장을 버리며, 사용 후 덱 맨 아래로 이동한다.
7. 수호석: 활로 2 이하 아군 그룹 옆 착수 시 그 그룹에 수호 1회를 부여하고, 다음 상대 착수의 포획을 1회 무효화한다.
8. 희생석: 상대 착수로 포획되면 다음 내 턴 패 한도 +1과 즉시 카드 1장 드로우. 초기 구현에서는 상대 손패 감소는 제외한다.
9. 카드 상세에 추천 연계를 표시하고 AI가 신규 효과의 실제 전략 가치를 평가하도록 확장한다.

## 제약

- 기존 바둑 합법수, 자충수, 단순패 규칙 유지
- 추가 착수는 부여하지 않음
- 모바일 380px 우선, hover 전용 금지
- 신규 런타임 의존성 금지
- strict TDD와 AGENTS.md evidence lifecycle 준수
- Claude는 계획/독립 검증만, Hermes/Codex만 제품 코드 수정
- commit/push 금지
