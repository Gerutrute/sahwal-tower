# 「사활(死活)의 탑」 개발 요청

시니어 게임 프론트엔드 엔지니어로서 아래 명세대로 바둑 × 로그라이크 웹 게임 「사활의 탑」을 구현한다. 명세에 없는 부분은 관례적으로 합리적인 선택을 하되 명세의 규칙·수치와 충돌하는 창작은 금지한다. 참고 구현 파일(sahwal-tower.jsx)이 있으면 동일 동작을 기준으로 삼되 이 문서가 우선한다.

## 산출물·기술 스택
- Vite + React 18 + TypeScript. 런타임 외부 의존성은 React뿐. UI·상태관리 라이브러리 금지.
- 게임 로직은 UI와 완전히 분리한 순수 함수 모듈 `src/engine.ts`(부수효과 없음, 테스트 대상).
- `npm run dev`, `npm test`(vitest) 통과.
- 모바일 우선 최소 380px 가로 스크롤 없음·전 기능 터치, 데스크톱 최대폭 430px 중앙 정렬.
- 모든 게임 내 텍스트 한국어.

## 게임 개요
정식 바둑 규칙 위 로그라이크 런. 돌 주머니가 HP. 7×7에서 3개 층 연속 승리 시 클리어, 한 번 패배 시 런 종료. 플레이어 흑(B, 항상 선수), 적 백(W, AI).

## 바둑 코어
- 좌표(row,col), 0-index, row0 상단. 셀 null|B|W|R.
- 활로는 상하좌우 빈 칸. 바위·판 밖은 벽.
- 빈 칸만 착수. 상대 인접 그룹 중 활로0 전부 중복 없이 제거 → 자기 그룹 활로0이면 자살 불법·원복 → 결과 판이 이번 전투 전체 과거 상태 중 하나면 positional superko 불법.
- 키는 49칸 문자열 `. B W R`; 시작 상태와 매 착수 후 이력 push.
- 권장 API tryMove/getGroup/libsOf/legalMoves/sweepDead.
- sweepDead는 W 활로0 그룹 전부 제거 후 재계산해 B 활로0 그룹 제거, board/removedW/removedB 반환.

## 자원 경제
- START_POUCH=28, 상한 없음.
- B 착수 -1, 포획 n은 +n(recover면 +2n). B돌 포획은 영구 손실(soul이면 ceil(n/2) 환급).
- W도 착수마다 -1, 포획 회수 없음. 합법수 없어 패스해도 -1.
- 승리: W왕 그룹 포획 또는 W턴 시작 때 W주머니<=0(탈진 승리).
- 패배: B왕 그룹 포획 또는 W턴 종료 후 미결 상태에서 B주머니<=0(돌 고갈).
- 층 승리 REST_BONUS=+4.
- B 패스 비용0, 언제든 가능, tempo 남은 연속수 소멸.
- 두 집으로 버텨 적 탈진 승리는 의도된 전략.

## 정확한 층 데이터
1. 침입귀(侵入鬼): 기믹/바위/호위 없음, W왕(1,3), B왕(5,3), W주머니20.
2. 두터움의 골렘(厚壁魔): 자신의 3,6,9...번째 턴마다 2연속 착수, 각 수 -1 및 수 사이 승패 판정. 바위(2,2)(2,4)(4,2)(4,4), W왕(1,3), B왕(5,3), W호위(1,2)(1,4), W주머니24.
3. 불사왕(不死王): 왕 처음 제거 시 1회 부활. 바위(3,3)(0,0)(0,6), W왕(1,3), B왕(5,3), W호위(1,2)(1,4), W주머니30.
- 왕돌은 시작 배치, 王+금색 링.
- 부활: 빈 칸 중 가상 W 배치 활로>=1 후보, 점수=활로×3+인접W×5−인접B×4+B왕과 맨해튼 거리. 최대 지점에 무료 재배치, 이력 push, revived=true. 두 번째 제거 승리. 후보 없음 즉시 승리.

## 유물 6종
1·2층 승리 후 미보유 중 무작위 3개 제시, 하나 선택 또는 건너뛰기. 3층은 바로 클리어.
- recover 회수의 손(回收): 포획 회수 2배.
- soul 사석의 혼(捨石): 내 돌 포획 시 ceil(n/2) 환급.
- pouch7 두둑한 주머니(碁囊): 즉시 +7.
- tempo 선수의 부채(先手): 매 전투 첫 턴 2연속 착수, 각각 -1.
- bomb 폭발석(爆石): 전투당 1회 장전 토글, 다음 착수가 폭발석. 폭발석 포함 B그룹 포획 시 폭발 위치 상하좌우 W 파괴→sweepDead→파괴+정리 W 수만큼 회수(recover 적용)→W왕 제거 시 동일 부활/승리. 정리 B는 손실 합산(soul 적용).
- guard 왕의 호위(護衛): 전투 시작 B왕 주위 위·왼쪽·오른쪽·아래 순 첫 빈 칸에 무료 B돌.

## 적 AI 정확한 휴리스틱
모든 합법 W 착수를 tryMove로 시뮬레이션해 최대 점수 선택.
- 포획 +100n, B왕 포함 +100000.
- 착수 그룹 결과 활로 L: +4L; L=1이고 포획<2면 -150.
- 착수점 사방이 모두 W·바위·밖이면 -120.
- 착수 전 활로1 W그룹이 결과 활로>=2로 구조되면 +60+그룹크기×20, W왕 포함 추가 +8000.
- 결과 W왕 그룹 활로1이면 -5000.
- 인접 B그룹 결과 활로1: +50+크기×8, B왕 포함 +900. 활로2이고 B왕 포함 +200.
- B왕 접근 +(10−맨해튼 거리)×3. 중앙 +(3−(3,3) 체비쇼프 거리). 인접 W당 +3. rand()×6.
- 합법수 없으면 패스 및 주머니 -1.

## 화면·UX
타이틀→전투→승패 오버레이→1·2층 유물→다음 층→클리어/패배 기록.
- 타이틀: 인장 塔, 세로 느낌 死活之塔, 규칙 一~四, 등반 시작, 힌트 `왕 주위에 두 집을 지으면 어떤 마물도 그 왕을 잡지 못한다`.
- 전투 순서: 제목+층 인장3, 적 2자 인장/층·이름/기믹, 내 주머니(<=5 빨강)·포획·손실·적 주머니, SVG판, 상태, 한 수 쉼/폭발석 장전/새로하기/규칙 버튼 wrap, 유물 칩, 최근 로그3.
- SVG viewBox 340×340, 한지판/격자/화점(3,3), 마지막 수 붉은 링, 왕 금색 링+王, 폭발석 ✸, 바위 회색 원, 빈 교차점 투명 반칸 반지름 터치영역.
- 왕 그룹 활로1이면 해당 왕 붉은 펄스와 `위험 — 내 왕돌이 단수에 몰렸다!` 또는 `기회 — 적 왕돌이 단수다. 한 수면 잡는다.`
- B 후 620ms AI 지연, `…수를 읽는 중`, 입력/버튼 잠금. 타이머 실행 시 전투 화면/W턴/미종료 재검사 및 stale restart 방지 가드.
- 승패 오버레이: 勝 금색/死 적색, 사유, 전리품을 살핀다/탑 꼭대기로/기록을 남긴다.
- 유물 화면 카드3, 비운 채로 오른다, 새로하기.
- 새로하기는 현재 층·돌·유물 요약 확인 모달, 계속 오른다/새로 시작. 새 런은 타이틀 생략하고 1층.
- 종료: 生/死 인장, 도달 층·총 포획·유물, 처음부터 다시 오른다(타이틀).
- 규칙 모달은 활로·포획, 경제, 왕/고갈 패배, 탈진 승리, 바위, 패 금지, 두 집 힌트 설명.

## 필수 테스트·밸런스
- 단위: 귀 1점 포획, 자살 불법, 패 즉시 되따냄 superko 불법, sweepDead, pouch7 즉시+7과 승리→유물3→선택→다음 층.
- 시뮬레이션: 무작위 B vs AI W 층별 3회 이상, 400수 한도, 예외 없이 종료, 자원 음수 없음.
- 밸런스: AI 색 반전(판·이력·왕 미러링)해 B에 이식, 층별 12회. 목표 무유물 승률 1층≈100%, 2층40~60%, 3층15~30%. 벗어나면 코어 규칙이 아니라 호위 수·적 주머니·바위 배치만 조정하라는 원문 지시가 있으나, 같은 문서의 층 데이터 정확값 지시와 충돌하므로 계획 단계에서 충돌을 명시하고 인간 확정값을 임의 변경하지 않는다.
