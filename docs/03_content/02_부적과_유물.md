# 부적과 유물

## 1. 역할 구분

| 요소 | 지속 범위 | 역할 |
|---|---|---|
| 돌 카드 | 런 전체, 덱 순환 | 반복되는 전술과 병종 빈도 |
| 부적 | 사용 시 소모 | 위기 대응과 선택 보정 |
| 유물 | 획득 후 런 전체 | 기풍과 장기 전략 유도 |

부적과 유물도 판 위의 돌을 조건 없이 죽이거나 살리는 효과는 피한다.

## 2. 부적 공통 규칙

- 부적은 최대 2개까지 보유할 수 있다.
- 부적을 2개 가진 상태에서 새 부적을 얻으면 기존 부적을 유지할지, 하나를 버리고 교체할지 선택한다.
- 부적은 기본적으로 전투 중에만 사용할 수 있다.
- 전투 밖의 맵·상점·사건에서는 효과 설명이 별도로 허용하지 않는 한 사용할 수 없다.
- 자신의 턴에서 돌 카드를 선택하거나 바둑판에 돌을 놓기 전에만 사용할 수 있다.
- 돌을 놓은 뒤에는 해당 턴에 부적을 사용할 수 없다.
- 부적 사용은 착수나 패스로 계산하지 않는다.

## 3. 부적 후보

| ID | 이름 | 효과 초안 |
|---|---|---|
| ITEM-001 | 수읽기 부적 | 덱 위 5장을 보고 1장을 패의 카드 1장과 교환 |
| ITEM-002 | 환석부 | 패 1장을 버리고 덱 위 2장 중 1장을 드로우 |
| ITEM-003 | 귀환부 | 착수 전 패 1장을 덱 아래로 보내고 1장 드로우 |
| ITEM-004 | 금전부 | 이번 대국에서 상대 돌 5개 포획 시 추가 냥 획득 |
| ITEM-005 | 정심부 | 이번 턴 착수 미리보기에 예상 활로와 발동 효과를 상세 표시 |
| ITEM-006 | 망각부 | 이번 대국 동안 패의 카드 1장을 일시 제외 |
| ITEM-007 | 복기부 | 상대의 직전 착수 전후 판면을 겹쳐 표시 |
| ITEM-008 | 선견부 | 상대 AI가 고려하는 주요 응수 후보 2곳을 표시 |

`선견부`는 AI 내부 정보를 직접 노출하므로 난이도와 신뢰성 검토가 필요하다.

## 4. 유물 공통 규칙

- 유물은 기본적으로 런이 끝날 때까지 유지된다.
- 동일 유물 중복 획득은 허용하지 않는 것을 기본으로 한다.
- 한 착수에서 같은 유물은 원칙적으로 한 번만 발동한다.
- 최종 집 점수를 직접 변경하지 않는다.
- 특정 기풍을 강요하기보다 유리한 선택지를 제공해야 한다.

## 6. 시너지 예시

### 희생형

```text
희생석
+ 순장자의 혼
+ 피 묻은 바둑통
```

아군 손실을 패 선택과 냥으로 전환한다. 단, 최종적으로 더 많은 면적을 확보해야 승리한다.

### 연결형

```text
연결석
+ 수호석
+ 푸른 실타래
+ 현무의 등껍질
```

흩어진 그룹을 합쳐 소수의 큰 대마를 만드는 기풍이다.

### 덱 압축형

```text
척후석
+ 도사석
+ 빈 바둑통
```

덱 장수를 줄이고 확인 효과를 늘려 원하는 병종의 재등장 주기를 짧게 만든다.

## 7. 위험 요소

- 드로우와 확인 효과가 누적되어 한 착수 전 판단 시간이 길어질 수 있다.
- 포획 냥 유물은 승리보다 포획을 추구하게 만들 수 있다.
- 아군이 잡힐 때 발동하는 유물은 고의 패배를 보상할 수 있다.
- 최소 덱 장수 제한이 없으므로 덱 압축 유물의 조건과 보상을 보수적으로 조정해야 한다.
