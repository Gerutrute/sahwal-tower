# 특수 돌

## 1. 공통 규칙

- 모든 특수 돌은 기본적으로 정상적인 바둑돌이다.
- 활로가 필요하며 상대에게 포획될 수 있다.
- 같은 색 돌과 연결되고 집과 면적 점수에 포함된다.
- 능력 조건을 충족하지 못해도 합법적인 위치라면 착수할 수 있다.
- 조건 없는 돌 파괴·이동·부활 능력은 사용하지 않는다.
- 카드 한 장은 대국 중 여러 번 순환할 수 있으므로 같은 병종 돌을 여러 개 배치할 수 있다.

## 2. 병종 역할 분류

| 분류 | 유도하는 바둑 행동 |
|---|---|
| 순환 | 덱 위 확인, 패 교환, 원하는 병종 탐색 |
| 포획 | 상대 돌 잡기와 전투적인 기풍 |
| 연결 | 약한 그룹 구조와 대마 관리 |
| 희생 | 사석, 유인, 버림돌 활용 |
| 확장 | 변·귀·중앙 등 특정 방향의 착수 |
| 대응 | 상대의 직전 행동에 맞춘 반격 |

## 3. MVP 핵심 병종

### STONE-001 일반석

- 등급: 기본
- 분류: 안정
- 효과: 없음
- 역할: 덱의 예측 가능성과 특수 효과의 밀도를 조절한다.
- 강화 초안: 강화하지 않거나 일반석 전용 유물로만 지원한다.

### STONE-002 척후석

- 등급: 일반
- 분류: 순환
- 효과: 착수 후 덱 위 2장을 확인하고 순서를 바꿀 수 있다.
- 강화: 확인 수가 3장으로 증가한다.
- 발동 제한: 착수당 1회

### STONE-003 장군석

- 등급: 일반
- 분류: 포획·경제
- 효과: 이 돌이 포함된 그룹이 상대 돌을 잡으면 추가 5냥을 얻는다.
- 강화: 추가 보상이 8냥으로 증가한다.
- 제한: 한 번의 착수에서 1회, 대국당 추가 냥 상한 적용

### STONE-004 기병석

- 등급: 일반
- 분류: 포획·순환
- 효과: 직전 자신의 착수로 상대 돌을 잡았다면, 이 카드가 패에 들어올 때 덱 위 카드 1장을 추가로 확인한다.
- 강화: 확인한 카드와 패의 카드 1장을 교환할 수 있다.
- 설계 주의: 즉시 추가 착수는 허용하지 않는다.

### STONE-005 수호석

- 등급: 일반
- 분류: 연결·회복
- 효과: 활로가 2 이하인 아군 그룹에 인접해 착수하면 덱 위 2장을 확인한다.
- 강화: 조건이 활로 3 이하로 완화된다.
- 목적: 위험한 그룹을 살리는 착수를 장려한다.

### STONE-006 희생석

- 등급: 일반
- 분류: 희생·순환
- 효과: 상대의 착수로 포획되면 다음 플레이어 턴의 패 한도가 1 증가한다.
- 강화: 패 한도 증가와 함께 덱 위 1장을 확인한다.
- 중첩: 여러 희생석이 동시에 잡히면 각각 발동한다.
- 제외: 자충수와 효과에 의한 자발적 제거에는 발동하지 않는다.

## 4. 확장 병종 후보

다음 목록은 콘텐츠 후보이며 수치는 플레이테스트 전 초안이다.

| ID | 이름 | 분류 | 효과 초안 |
|---|---|---|---|
| STONE-007 | 연결석 | 연결 | 서로 다른 아군 그룹 2개 이상을 연결하면 덱 위 2장 확인 |
| STONE-008 | 도사석 | 순환 | 착수 후 패 1장을 버리고 1장 드로우 가능 |
| STONE-009 | 귀석 | 확장 | 귀의 지정 범위에 착수하면 다음 드로우 후보 2장 중 선택 |
| STONE-010 | 변방석 | 확장 | 변에 착수하고 활로가 3 이상이면 냥 소량 획득 |
| STONE-011 | 천원석 | 확장 | 중앙 지정 범위에 착수하면 이번 턴 유물 발동 상태 표시 강화 |
| STONE-012 | 쐐기석 | 연결·절단 | 두 상대 그룹 사이의 절단점에 착수하면 덱 위 2장 확인 |
| STONE-013 | 고립석 | 침투 | 인접 아군 없이 착수하면 다음 턴 패의 카드 1장 교환 가능 |
| STONE-014 | 대마석 | 연결 | 크기 5 이상인 아군 그룹과 연결되면 카드 1장 추가 확인 |
| STONE-015 | 숨돌 | 생존 | 착수 후 자신의 그룹 활로가 정확히 1이면 다음 턴 패 한도 +1 |
| STONE-016 | 반격석 | 대응 | 직전 상대 턴에 아군이 잡혔다면 착수 후 덱 위 3장 확인 |
| STONE-017 | 호위석 | 연결 | 장군석이 포함된 그룹과 연결되면 장군석의 다음 냥 발동량 증가 |
| STONE-018 | 빈집석 | 영역 | 자신의 돌로만 둘러싸인 영역 안에 착수하면 사용 카드를 덱 아래로 보냄 |
| STONE-019 | 패석 | 대응 | 패가 발생한 착수 후 다음 드로우 후보를 추가 확인 |
| STONE-020 | 유랑석 | 확장 | 현재 가장 가까운 아군 그룹과 일정 거리 이상이면 카드 교환 가능 |

## 5. 빌드 예시

### 공격 기풍

```text
장군석 + 기병석 + 반격석
```

포획을 통해 경제와 덱 탐색을 동시에 얻는다.

### 희생 기풍

```text
희생석 + 고립석 + 반격석
```

침투한 돌을 사석으로 활용하고 다음 대응 수의 선택지를 늘린다.

### 대마 기풍

```text
수호석 + 연결석 + 대마석
```

소수의 큰 그룹을 연결하고 약한 돌을 살리는 플레이를 유도한다.

### 확장 기풍

```text
귀석 + 변방석 + 유랑석
```

판의 여러 구역에 빠르게 기반을 만들고 후반에 연결한다.

## 6. 밸런스 점검 항목

- 특정 병종이 효과와 관계없이 일반석보다 항상 좋은가?
- 효과 조건을 만들기 위해 나쁜 바둑 수를 두는 것이 과도하게 보상되는가?
- 한 장만 넣어도 순환 때문에 같은 병종이 지나치게 많이 쌓이는가?
- 포획형 냥 보상이 대국 승리보다 돌 잡기를 우선하게 만드는가?
- 판 크기가 커질 때 효과 발동 빈도가 지나치게 변하는가?
