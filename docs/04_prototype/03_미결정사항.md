# 결정 및 미결정 사항

## 1. 기본 확정 결정

| ID | 항목 | 확정 내용 |
|---|---|---|
| Q-001 | 플레이어 선후수 | 플레이어는 항상 흑, AI는 항상 백으로 시작 |
| Q-002 | 시작 덱과 패 | 시작 덱 10장, 기본 패와 패 한도 4장 |
| Q-003 | MVP 판 확장 | 1막은 7×7, 2막은 9×9 |
| Q-004 | 패 규칙 | MVP는 단순패 사용 |
| Q-005 | AI 덱 | 1막 기본 덱+1회 부활, 2막 강한 고유 특성+개성 있는 카드 |
| Q-006 | 화폐 | `냥`. 고양이 울음소리에서 비롯된 세계관 명칭 |
| Q-007 | 덱 제거 | 최소 장수 제한 없음. 상점 한 곳당 최대 1장 제거 |
| Q-008 | 병종 중복 | 같은 병종을 판 위에 여러 개 배치 가능 |
| Q-009 | 부적 보유 | 최대 2개 보유. 초과 획득 시 기존 부적과 교체 선택 |
| Q-010 | 보상 거절 | 세 후보를 모두 거절하면 아무것도 받지 않음 |
| Q-011 | 패배 | 모드와 관계없이 한 번 패배하면 즉시 런 종료 |
| Q-012 | MVP 최대 판 | 9×9까지 제작 |
| Q-013 | 죽은 돌 보조 | MVP 범위에서 제외 |
| Q-014 | 최종 보스 | 플레이어에게 없는 고유 특성과 기믹 사용 |
| Q-015 | 영구 성장 | 돌 카드·부적·유물 후보군을 해금하여 이후 런에 등장시킴 |

## 2. 추가 확정 결정

| ID | 항목 | 확정 내용 |
|---|---|---|
| Q-016 | AI의 1회 부활 | AI가 첫 패배 후 같은 판면에서 2단계 시작 |
| Q-017 | 부적 사용 시점 | 자신의 턴에서 돌을 놓기 전에만 사용 |
| Q-018 | 막별 진행 | 지도 노드 5개를 거친 뒤 보스전 시작 |
| Q-018-1 | 실제 대국 수 | 선택한 지도 노드에 따라 달라지며 고정하지 않음 |
| Q-018-2 | 판 크기 | 1막 전투는 7×7, 2막 전투는 9×9 |
| Q-019 | 판 크기별 덤 | 개발과 플레이테스트를 진행하며 결정 |
| Q-020 | AI 부활 초기화 | 판면과 진행 상태를 유지하고 AI에 새로운 특성만 추가 |
| Q-021 | 일반 전투 노드 | 한 막의 다섯 지도 노드 중 최대 3개까지 통과 가능. 보스 제외 |
| Q-022 | AI 부활 재개 | 종료·연속 패스 상태 해제 후 새 특성의 AI 전용 착수 1회, 이어서 플레이어 정상 턴 |
| Q-023 | 최소 일반 전투 | 한 막의 모든 유효 경로에 최소 1개 보장. 보스 제외 |

## 3. 플레이테스트 조정 항목

- 7×7·9×9 덤
- 1막과 2막의 전투 노드 등장 가중치
- AI 부활 2단계의 난이도 상승 폭
- AI 부활 전용 착수의 후보 생성 규칙과 전략적 영향
- 한 런의 평균 대국 수와 목표 플레이 시간

## 4. MVP 이후 검토

- 상황적 슈퍼코 도입 여부
- 11×11 이상의 판 확장 순서
- 죽은 돌 후보 자동 표시
- 최종 보스의 구체적인 전용 기믹
- 영구 해금 콘텐츠의 초기 잠금 비율과 해금 속도
