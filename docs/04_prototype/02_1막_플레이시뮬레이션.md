# 1막 플레이 시뮬레이션

## 1. 목적

이 문서는 7×7 대국에서 바둑 수읽기, 덱 순환과 유물 시너지가 한 턴에 어떻게 연결되는지 확인하기 위한 예시다. 실제 AI 수순을 확정하는 기보가 아니다.

## 2. 시작 상태

### 플레이어

- 색: 흑 고정
- 덱: 총 10장. 일반석 6, 척후석 1, 수호석 1, 희생석 1, 장군석 1로 예시
- 패 한도: 4
- 유물: 순장자의 혼
- 부적: 수읽기 부적 1개

### 상대

- 인물: 성급한 검사
- 기풍: 포획 우선
- 주력 병종: 장군석, 기병석
- 공통 패시브: 첫 패배 후 기존 판면을 유지하고 새로운 특성을 얻어 2단계 시작

### 시작 패

```text
[일반석] [희생석] [일반석] [장군석]
```

## 3. 초반

플레이어는 일반석으로 귀의 기반을 만든다. 사용한 일반석 카드는 버림 더미로 이동하고 덱에서 카드 한 장을 보충한다.

```text
카드 상태

패: 일반석 / 희생석 / 장군석 / 척후석
버림: 일반석
```

상대는 플레이어의 돌을 공격하기 위해 가까이 붙인다.

## 4. 희생석 침투

플레이어는 희생석을 상대 돌 사이의 삭감 지점에 놓는다. 희생석은 즉시 이득을 얻지 않으며 정상적인 활로를 가진 돌로 남는다.

상대가 희생석을 포획하면 다음 순서로 처리한다.

1. 희생석을 판에서 제거한다.
2. 희생석의 피포획 효과가 큐에 등록된다.
3. `순장자의 혼`이 피포획을 감지한다.
4. 다음 플레이어 턴의 패 한도가 1 증가한다.
5. 다음 드로우 후보 확인 수가 1 증가한다.

## 5. 반격 준비

다음 플레이어 턴의 패:

```text
[일반석] [장군석] [척후석] [수호석] [일반석]
```

플레이어는 척후석을 사용해 덱 위의 카드 순서를 확인하고 장군석이 다시 등장하기 좋은 순서로 조정한다.

이 과정에서 희생석은 직접 점수를 만들지 않았지만 다음 수의 선택 폭을 늘렸다.

## 6. 장군석 포획

플레이어는 장군석으로 상대 그룹의 마지막 활로를 메운다.

```text
장군석 착수
→ 상대 그룹 포획
→ 잡힌 돌 전체 제거
→ 장군석 그룹의 포획 성공 확인
→ 추가 냥 획득
→ 장군석 카드는 버림 더미로 이동
```

판 위의 장군석은 계속 장군석 속성을 유지하며, 장군석 카드 자체는 이후 덱 재순환으로 다시 등장할 수 있다.

## 7. 종반

양측은 남은 빈 영역을 정리한다. 플레이어는 죽었다고 판단한 상대 돌을 계가 전에 직접 포획한다.

플레이어가 패스하고 상대도 패스하면 다음과 같이 계산한다.

```text
흑 점수 = 흑돌 수 + 흑 영역
백 점수 = 백돌 수 + 백 영역 + 덤
```

포획으로 얻은 냥은 대국 점수가 아니라 대국 승리 확정 후 런 경제에 반영한다.

## 8. 대국 후

```text
1단계 승리 판정
→ AI 부활
→ 기존 판면·덱·패·유물 상태 유지
→ AI에 새로운 특성 추가
→ 종료 판정·연속 패스 상태 해제
→ 새 특성의 AI 전용 착수 1회
→ 플레이어 턴부터 2단계 계속 진행
→ 2단계까지 승리
→ 승리 냥 + 포획 추가 냥 정산
→ 세 개의 보상 제시
→ 장군석 / 수읽기 부적 / 희생석 강화 중 하나 선택
→ 다음 맵 노드 선택
```

1단계 승리만으로는 지도 전투 노드가 완료되지 않는다. 판면을 초기화하지 않고 AI에 새로운 특성만 추가한다. 종료 상태와 연속 패스 횟수를 초기화한 뒤, AI가 새 특성의 전용 착수를 1회 수행한다. 전용 착수의 포획과 효과 처리가 끝나면 플레이어 턴부터 정상 진행한다. 2단계에서 패배하면 즉시 런이 종료된다.

## 9. 이 시뮬레이션에서 확인할 문제

- 희생석의 보상이 사석의 손해를 과도하게 상쇄하지 않는가?
- 다음 턴 패가 5장이 되었을 때 선택 시간이 지나치게 길어지지 않는가?
- 장군석 추가 냥이 집보다 포획을 우선하게 만들지 않는가?
- 카드는 재순환하고 판 위 돌은 남는다는 개념을 UI로 이해할 수 있는가?
- 계가 전에 죽은 돌을 직접 잡는 과정이 자연스러운가?
- AI의 전용 착수가 1단계에서 정리된 판면에 새로운 전략적 문제를 만드는가?
