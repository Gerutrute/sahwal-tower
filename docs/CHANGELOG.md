# 변경 이력

## 0.2.3 — 2026-08-17

### 확정

- AI 부활 시 종료 상태와 연속 패스 횟수를 초기화
- AI의 새 특성이 발동하는 전용 착수를 1회 처리한 뒤 플레이어 턴부터 2단계 재개
- 모든 유효 지도 경로에 보스와 별도로 일반 전투 노드를 최소 1개, 최대 3개 배치

### 세부화

- AI 전용 착수는 일반 손패를 소비하거나 기본 보충 드로우를 발생시키지 않음
- 전용 착수도 별도 예외가 명시되지 않으면 기본 바둑의 합법 수와 효과 처리 순서를 따름

## 0.2.2 — 2026-08-17

### 확정

- 부적은 자신의 턴에 돌을 놓기 전에만 사용
- AI 부활 시 기존 판면과 진행 상태를 유지
- AI 부활 후 판을 초기화하지 않고 새로운 특성만 추가해 2단계 진행
- 한 막에서 플레이어가 거칠 수 있는 일반 전투 노드를 최대 3개로 제한

### 계속 검토

- AI 부활 직후 어느 쪽부터 착수하는지
- 첫 단계가 양측 연속 패스로 끝났을 때 2단계를 의미 있게 재개하는 방법
- 한 막에서 보장할 최소 일반 전투 노드 수

## 0.2.1 — 2026-08-17

### 수정

- 7×7 대국 2회 고정 규칙을 제거
- 각 막에서 지도 노드 5개를 거친 뒤 보스전에 진입하도록 변경
- 선택한 노드 종류에 따라 보스 전까지의 실제 대국 횟수가 달라지도록 확정
- 1막은 7×7, 2막은 9×9로 진행하고 MVP는 2막 보스에서 종료
- 1막 AI의 부활을 `첫 패배 후 2차전 시작` 방식으로 확정
- 7×7·9×9 덤은 개발 중 플레이테스트로 결정

### 계속 검토

- AI 부활 후 2차전에서 판면·덱·유물을 초기화할 범위
- 부적의 전투 내 세부 사용 시점

## 0.2.0 — 2026-08-17

### 확정

- 플레이어는 항상 흑, AI는 항상 백으로 시작
- 시작 덱 10장, 기본 패와 패 한도 4장
- MVP 진행을 7×7 대국 2회 후 9×9 확장으로 설정
- MVP 최대 판 크기를 9×9로 제한
- 패 규칙을 단순패로 확정
- 1막 AI는 기본 덱과 1회 부활 패시브, 2막 AI는 강한 고유 특성과 개성 있는 카드 사용
- 화폐 명칭을 `냥`으로 확정하고 고양이 울음소리에서 유래한 설정 추가
- 상점 한 곳당 돌 카드 제거 1회, 최소 덱 장수 제한 없음
- 같은 병종의 판 위 중복 배치 허용
- 부적 보유 한도 2개, 초과 획득 시 교체 선택
- 세 보상 전부 거절 시 대체 보상 없음
- 한 번의 대국 패배로 즉시 런 종료
- 최종 보스는 플레이어에게 없는 고유 특성과 기믹 사용
- 영구 성장으로 돌 카드·부적·유물 후보군 해금

### 추가 검토

- 1막 AI의 `1회 부활` 대상과 정확한 처리 방식
- 부적을 전투 중 사용할 수 있는 세부 시점
- 흑 고정에 따른 7×7·9×9 덤 수치

## 0.1.0 — 2026-08-17

### 추가

- 최초 기획 문서집 구성
- 게임 비전, 게임 루프 및 설계 원칙 정리
- 돌 카드와 바둑판 위의 돌을 분리하는 순환형 덱 규칙 확정
- 착수 불가능, 자동 패스, 연속 패스 종료 규칙 추가
- 면적 계가, 잔존 돌 생존 처리 및 소수점 덤 규칙 추가
- 특수 돌, 부적, 유물, 적 기사, 보스, 이벤트 초안 정리
- 7×7 MVP 범위와 플레이테스트 지표 정의
- 미결정 사항을 우선순위별로 분리

### 당시 다음 버전 예정

- 플레이어 선후수 방식과 판 크기별 덤 확정
- 1막 바둑판 성장 방식 확정
- 시작 덱 및 손패 수치 확정
- 패 규칙과 반복 국면 방지 규칙 확정
- 첫 플레이테스트 결과 반영
