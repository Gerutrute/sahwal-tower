## 3. 현재 확정된 코어 규칙

1. 돌 덱은 실제 돌의 보유 수량이 아니라 병종의 출현 순서와 빈도를 뜻한다.
2. 돌 카드를 사용하면 카드는 버림 더미로 가고, 바둑판에는 해당 병종의 돌이 남는다.
3. 뽑기 더미가 비면 버림 더미를 섞어 새 뽑기 더미로 만든다.
4. 덱 소진 때문에 패배하거나 착수할 수 없게 되지 않는다.
5. 특수 돌도 정상적인 바둑돌이며 활로·연결·포획·집 규칙을 따른다.
6. 합법적인 착수 지점이 없으면 자동 패스한다.
7. 양측이 연속으로 패스하면 대국을 종료하고 면적 방식으로 계가한다.
8. 대국 종료 시 판 위에 남은 돌은 모두 살아 있는 돌로 계산한다. 죽은 돌은 종료 전에 직접 잡아야 한다.
9. 후수에게 소수점 덤을 주어 무승부를 방지한다.
10. 유물과 특수 효과는 원칙적으로 최종 점수를 직접 변경하지 않는다.
11. 플레이어는 항상 흑으로 시작하고 AI는 백을 맡는다.
12. 시작 덱은 10장, 기본 패와 패 한도는 4장이다.
13. 각 막은 지도 노드 5개를 선택해 거친 뒤 보스전에 진입한다.
14. 1막의 대국은 7×7, 2막의 대국은 9×9이며 MVP는 2막 보스까지 제작한다.
15. 지도에서 전투·상점·사건 등을 선택하므로 보스 전까지의 실제 대국 횟수는 경로에 따라 달라진다. 모든 유효 경로에는 보스와 별도로 일반 전투 노드가 1~3개 포함된다.
16. MVP의 패 규칙은 단순패를 사용한다.
17. 화폐 명칭은 `냥`이며, 고양이 울음소리에서 유래한 세계관 설정을 사용한다.
18. 상점 한 곳에서 제거할 수 있는 돌 카드는 1장이며 최소 덱 장수 제한은 없다.
19. 같은 병종은 판 위에 여러 개 배치할 수 있다.
20. 부적은 최대 2개까지 보유하며 초과 획득 시 교체 여부를 선택한다. 부적은 자신의 턴에 돌을 놓기 전에만 사용할 수 있다.
21. 세 보상을 모두 거절하면 아무것도 얻지 않는다.
22. 대국에서 한 번 패배하면 모드와 관계없이 즉시 런이 종료된다.
23. 1막 AI는 첫 패배 후 한 번 부활한다. 기존 판면과 모든 진행 상태를 유지한 채 AI에 새로운 특성을 추가하고, 그 특성의 전용 착수를 1회 수행한 다음 플레이어 턴부터 2단계를 계속한다.
24. 영구 성장은 돌 카드·부적·유물 후보군을 해금하는 방식이며 직접 점수 강화는 없다.
