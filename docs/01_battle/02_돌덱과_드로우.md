# 돌 덱과 드로우

## 1. 핵심 정의

> 돌 덱은 실제 바둑알의 수량이 아니라, 착수할 때 사용할 병종의 출현 순서와 빈도를 뜻한다.

돌 카드를 사용했다고 해서 해당 카드가 판 위에 붙어 있는 것은 아니다. 카드는 덱을 순환하고, 판 위의 돌은 병종 정보를 가진 별도 객체로 남는다.

## 2. 카드 상태

```text
뽑기 더미 → 현재 패 → 사용 → 버림 더미
     ↑                       ↓
     └──── 덱 소진 시 섞기 ──┘
```

| 상태 | 설명 |
|---|---|
| 뽑기 더미 | 앞으로 등장할 돌 카드 |
| 현재 패 | 이번 턴에 선택할 수 있는 돌 카드 |
| 버림 더미 | 이미 사용했으며 다음 순환을 기다리는 카드 |
| 판 위의 돌 | 카드와 독립적으로 존재하는 병종 표시 돌 |

## 3. 기본 순환 규칙

1. 대국 시작 시 덱을 섞는다.
2. 시작 패 한도까지 카드를 뽑는다.
3. 착수할 돌 카드 한 장을 선택한다.
4. 착수 처리 후 사용 카드를 버림 더미로 보낸다.
5. 패 한도까지 한 장을 보충한다.
6. 뽑기 더미가 비면 버림 더미를 섞어 새로운 뽑기 더미를 만든다.

따라서 덱 소진으로 패배하거나 더 이상 착수할 수 없게 되지 않는다.

## 4. 판 위의 병종 유지

장군석 카드를 사용한 예:

```text
장군석 카드 선택
→ 바둑판에 장군석 배치
→ 장군석 카드는 버림 더미로 이동
→ 바둑판의 장군석은 장군석 속성을 유지
→ 덱 순환 후 장군석 카드를 다시 뽑을 수 있음
```

덱에 장군석 카드가 1장이라도 한 대국에서 장군석을 여러 개 놓을 수 있다. 카드 수는 최대 배치 수가 아니라 등장 빈도를 결정한다.

## 5. 포획과 카드 상태

- 판 위의 특수 돌이 잡혀도 같은 이름의 카드를 찾아 이동시키지 않는다.
- 잡힌 돌의 피포획 효과만 처리하고 판에서 제거한다.
- 해당 병종 카드는 원래의 덱 순환 상태를 유지한다.
- 특정 유물이 명시적으로 덱에 카드를 생성하거나 제거할 때만 덱 구성이 변한다.

## 6. 시작 덱 수치와 구성안

MVP의 총 10장은 확정이며, 아래 병종 비율은 플레이테스트용 구성안이다.

```text
총 10장

일반석 × 6
척후석 × 1
수호석 × 1
희생석 × 1
선택 병종 × 1
```

| 항목 | 초안 값 |
|---|---:|
| 덱 크기 | 10장 |
| 시작 패 | 4장 |
| 기본 패 한도 | 4장 |
| 턴당 기본 착수 | 1회 |
| 사용 후 보충 | 패 한도까지 |

시작 덱은 10장으로 고정한다. 카드 추가와 제거에 따라 런 도중 덱 장수는 달라질 수 있다.

## 7. 일반석의 역할

일반석은 능력이 없는 불필요한 카드가 아니다.

- 예측 가능한 착수를 제공한다.
- 특수 능력의 연쇄로 인한 인지 부하를 낮춘다.
- 덱 제거 시 특수 돌 출현 빈도가 높아지는 대가를 만든다.
- 일반석 전용 유물과 덱 압축 빌드의 기준점이 된다.

## 8. 패 조작

| 효과 | 처리 원칙 |
|---|---|
| 확인 | 지정된 수만큼 덱 위를 보고 원래 위치 또는 새 순서로 반환 |
| 교환 | 패의 카드를 버리고 같은 수만큼 드로우 |
| 추가 드로우 | 임시 패 한도를 초과해 카드를 보유할 수 있음 |
| 생성 | 이번 대국에만 임시 카드를 버림 더미 또는 패에 추가 |
| 제거 | 런의 덱에서 영구 제거하거나 이번 대국에서만 제외하는지 명시 |

## 9. 덱이 비는 예외

정상적인 덱 크기가 패 한도보다 크면 착수 후 항상 버림 더미에 최소 1장이 있으므로 재순환할 수 있다.

효과로 덱 전체가 일시 제외되어 뽑기 더미와 버림 더미가 모두 비는 경우에는 **임시 일반석 카드**를 패에 생성한다. 이 카드는 사용 후 사라지며 런의 덱에 추가되지 않는다.

## 10. 덱 제거 및 중복 배치

- 최소 덱 장수 제한은 없다. 플레이어가 원하면 상점을 거쳐 모든 영구 카드를 제거할 수 있다.
- 상점 한 곳에서 제거할 수 있는 돌 카드는 최대 1장이다.
- 덱이 완전히 비면 매 턴 임시 일반석 카드를 생성하여 기본 착수를 보장한다.
- 같은 병종 카드는 순환할 수 있으며 판 위에 같은 병종 돌을 여러 개 놓을 수 있다.

## 11. AI 덱 방향

- 1막 AI는 기본 덱을 중심으로 사용하며, 처음 패배하면 한 번 부활하여 2단계를 시작한다.
- 2막 AI는 플레이어가 일반적인 덱만으로 쉽게 이기기 어려운 고유 특성과 개성 있는 카드를 사용한다.
- AI의 고유 패시브와 카드는 플레이어가 반드시 획득할 수 있는 콘텐츠일 필요가 없다.
- 1막 스테이지를 승리하려면 부활한 AI의 2단계까지 이겨야 한다.
- 부활 시 판면, 손패, 뽑기·버림 더미, 판 위 병종, 유물 발동 상태를 그대로 유지한다.
- AI에 새로운 특성만 추가하고 종료 상태를 해제한다.
- 새 특성의 전용 착수를 1회 수행한 뒤 플레이어의 정상 턴부터 같은 대국을 계속한다.
