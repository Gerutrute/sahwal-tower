# 효과 처리 순서와 예외

## 1. 목적

특수 돌, 부적과 유물이 동시에 발동할 때 결과가 매번 같도록 처리 우선순위를 정의한다.

## 2. 기본 우선순위

한 번의 착수에서 다음 순서로 처리한다.

| 우선순위 | 처리 |
|---:|---|
| 1 | 착수 위치와 패·자충수의 합법성 판정 |
| 2 | 돌을 판에 배치 |
| 3 | 인접한 상대 그룹 포획 및 제거 |
| 4 | 피포획 돌의 효과 발동 |
| 5 | 착수 돌 또는 그룹의 포획 성공 효과 발동 |
| 6 | 활로·연결·그룹 수를 참조하는 효과 발동 |
| 7 | 냥 및 런 경제 효과 반영 |
| 8 | 패·덱 조작 효과 반영 |
| 9 | 사용 카드 버림 및 기본 보충 드로우 |
| 10 | 턴 종료 효과 처리 |

## 3. 동시 포획

- 한 번의 착수로 여러 그룹이 잡히면 모든 돌을 먼저 제거한다.
- 제거가 완료된 최종 판면을 기준으로 후속 활로와 연결을 계산한다.
- 여러 희생석이 동시에 잡히면 각각의 효과를 발동한다.
- 장군석 그룹이 여러 그룹을 동시에 잡아도 기본적으로 포획 사건은 1회로 계산한다.
- 효과가 잡힌 돌 수를 참조하면 제거된 전체 돌 수를 사용한다.

## 4. 효과 큐

동일 우선순위에서 여러 효과가 발생하면 다음 규칙을 적용한다.

1. 현재 턴을 진행한 쪽의 돌 효과
2. 현재 턴을 진행한 쪽의 유물 효과
3. 상대의 피포획 돌 효과
4. 상대의 유물 효과
5. 동일 묶음 안에서는 획득 순서

플레이어가 순서를 선택하게 하는 방식은 전략성을 높이지만 매 착수의 조작량도 늘리므로 MVP에서는 자동 순서를 사용한다.

## 5. 정보 갱신 시점

- 활로 수: 모든 포획 제거가 끝난 뒤 다시 계산
- 그룹 수: 포획과 연결 처리가 끝난 최종 판면에서 계산
- 살아 있는 돌: MVP에서는 판 위에 남은 돌을 의미
- 포획 누적 수: 실제로 제거된 돌 수를 즉시 누적
- 패 한도: 효과가 발동한 시점부터 지정된 종료 시점까지 적용

## 6. 패스와 효과

- 패스는 착수가 아니므로 착수 시·착수 후 효과를 발동하지 않는다.
- 턴 시작 및 턴 종료 효과는 패스 여부와 관계없이 처리한다.
- 패스로 카드를 버리거나 뽑지 않는다.
- ‘다음 착수’ 효과는 패스를 건너뛰고 실제 착수가 발생할 때까지 유지한다.

## 7. 대국 종료 직전 효과

- 두 번째 연속 패스가 선언되면 턴 종료 효과를 먼저 처리한다.
- 효과가 판면을 변경하지 않는다면 계가로 이동한다.
- MVP에서는 대국 종료 효과가 새로운 돌을 생성하거나 제거하지 못한다.
- 냥 보상 효과는 최종 계가 이후 대국 결과가 확정된 다음 정산한다.

## 8. 무한 반복 방지

- 한 효과가 자기 자신을 직접 다시 발동시킬 수 없다.
- 한 번의 착수에서 같은 유물은 기본적으로 한 번만 발동한다. 예외는 설명에 명시한다.
- 생성 카드가 다시 생성 효과를 일으키는 경우 착수당 생성 횟수 상한을 둔다.
- 처리 큐가 안전 상한을 넘으면 추가 효과를 중단하고 로그를 남긴다.

## 9. AI 부활 전용 착수

- 1단계 승리 판정 뒤 종료 상태와 연속 패스 횟수를 초기화한다.
- AI에 새 특성을 추가한 직후, 그 특성에 명시된 전용 착수를 1회 처리한다.
- 전용 착수는 기본 착수와 같은 1~8번 우선순위를 따르되 손패 카드 사용·버림·기본 보충 드로우는 생략한다.
- 전용 착수의 모든 효과 처리가 끝난 뒤 플레이어의 정상 턴을 시작한다.
- 합법적인 전용 착수 후보가 없으면 자동 패스로 기록하고 플레이어 턴으로 넘어간다.

## 10. 표시 원칙

착수 미리보기에서 다음 정보를 표시한다.

- 포획될 상대 돌
- 착수 후 해당 그룹의 예상 활로
- 발동 예정인 돌·유물 효과
- 예상 드로우 또는 냥 변화
- 패 또는 자충수로 착수할 수 없는 이유
- AI 부활 전용 착수의 출처가 된 새 특성과 적용 결과

## 11. 테스트가 필요한 경계 사례

- 희생석 여러 개와 장군석이 같은 착수에서 상호작용
- 수호석 착수로 두 아군 그룹이 동시에 연결
- 포획으로 여러 빈 영역이 하나로 합쳐짐
- 덱 재순환과 추가 드로우가 동시에 발생
- 마지막 합법 수에서 포획과 자동 패스가 이어짐
- 패스 직전 적용된 ‘다음 턴’ 효과의 지속 시간
- 연속 패스 직후 AI 전용 착수로 포획이 발생하는 경우
- AI 전용 착수 후보가 없어 자동 패스로 처리되는 경우
