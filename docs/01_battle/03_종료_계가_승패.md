# 대국 종료·계가·승패

## 1. 종료 조건

다음 중 하나를 충족하면 대국 종료 단계로 이동한다.

1. 양측이 연속으로 패스한다.
2. 양측 모두 합법적인 착수 지점이 없어 자동 패스한다.
3. 한쪽이 기권한다.
4. 특정 보스전의 명시적인 종료 조건을 충족한다.

일반 대국에는 체력이나 돌 수 소진에 의한 패배 조건을 두지 않는다.

## 2. 바둑판이 가득 찬 경우

합법적인 기본 바둑에서는 판이 완전히 돌로 채워진 상태가 유지되기 어렵다.

- 마지막 빈칸에 놓고 상대를 잡지 못하면 자충수이므로 불법이다.
- 상대를 잡으면 잡힌 자리가 새로운 빈칸이 된다.

그러나 합법적인 착수 지점이 하나도 없는 경우는 처리해야 한다. 이때 해당 턴을 자동 패스로 처리하고, 양측 자동 패스가 이어지면 계가한다.

## 3. 계가 방식

디지털 게임에서 자동 판정을 명확하게 하기 위해 면적 방식을 사용한다.

```text
최종 점수 =
판 위에 남은 자신의 돌 수
+ 자신의 돌로만 둘러싸인 빈 교차점 수
+ 덤
```

연결된 빈 영역의 경계에 양쪽 색이 모두 닿아 있으면 중립 영역으로 보고 어느 쪽에도 점수를 주지 않는다.

## 4. 죽은 돌 처리

### MVP 확정 규칙

> 계가 시 판 위에 남아 있는 모든 돌은 살아 있는 돌로 계산한다.

상대 돌이 죽었다고 판단한다면 대국 종료 전에 직접 포획해야 한다. 자동 계가가 사활을 추론해 돌을 제거하지 않는다.

이 규칙의 목적:

- AI와 플레이어 사이의 사활 판정 분쟁 방지
- 특수 돌로 인해 기존 사활 판정이 흔들리는 문제 방지
- 같은 판면에서 항상 같은 결과 보장
- 초기 구현 범위 축소

## 5. 정식 버전의 판정 보조안

19×19에서 죽은 돌을 끝까지 직접 잡는 과정이 길어질 경우 다음 절차를 검토한다.

1. 게임이 죽은 돌 후보를 표시한다.
2. 플레이어가 동의하면 제거 후 계가한다.
3. 동의하지 않으면 대국을 재개한다.
4. 문제가 되는 돌을 직접 잡거나 살린 뒤 다시 패스한다.

자동 후보 표시는 편의 기능이며 최종 규칙을 대신하지 않는다.

## 6. 덤과 무승부 방지

후수에게 `.5` 단위의 덤을 부여한다. 돌과 영역 점수가 정수이므로 최종 동점이 발생하지 않는다.

판 크기별 덤은 플레이테스트로 결정한다.

| 판 크기 | 덤 초안 | 상태 |
|---:|---:|---|
| 7×7 | 미정 | MVP 플레이테스트로 조정 |
| 9×9 | 미정 | MVP 플레이테스트로 조정 |
| 11×11 이상 | 미정 | MVP 이후 결정 |

플레이어가 흑으로 고정되므로 정확한 덤은 판 크기별 플레이어 승률을 수집해 조정한다.

## 7. 특수 효과와 점수

- 특수 돌과 유물은 최종 집 점수를 직접 더하거나 빼지 않는 것을 원칙으로 한다.
- 냥은 런 경제에만 쓰이며 대국 점수에 포함되지 않는다.
- 보스 특수 게이지도 별도 승리 조건으로 명시되지 않는 한 점수에 포함되지 않는다.
- 점수 변경 효과를 도입한다면 0.5점 단위를 사용하지 않아 덤의 무승부 방지 기능을 유지한다.

## 8. 기권

- 플레이어는 메뉴에서 기권할 수 있다.
- AI는 승률이 극단적으로 낮더라도 MVP에서는 기권하지 않는다.
- 정식 버전에서는 명백한 패배 상태에서 AI 기권을 허용하되 복기 선택지를 제공한다.

## 9. 결과 화면

결과 화면에는 다음 정보를 표시한다.

- 흑과 백의 돌 점수
- 흑과 백의 영역 점수
- 덤
- 최종 점수 및 점수 차
- 포획한 돌 수
- 발동한 주요 유물과 병종 효과
- 결정적인 착수 후보 1~3개

## 10. 패배와 런 종료

- 플레이어가 대국에서 패배하거나 기권하면 즉시 해당 런을 종료한다.
- 초심자·일반·고난도 모드 모두 같은 원칙을 사용한다.
- 패배 후 같은 대국을 재시도하는 기본 기능은 제공하지 않는다.
- AI 전용 부활 패시브는 플레이어의 런 부활과 별개의 전투 기믹으로 취급한다.
- 1막 AI에게 처음 승리하면 보상 단계로 가지 않고 AI가 부활하여 2단계를 시작한다.
- 2단계는 기존 판면과 덱·패·유물 상태를 유지한다.
- 대국 종료 상태와 연속 패스 판정을 해제하고 AI에 새로운 특성을 추가한다.
- AI는 새 특성이 발동하는 전용 착수를 즉시 1회 수행한다.
- 전용 착수의 포획과 효과 처리가 모두 끝나면 플레이어의 정상 턴부터 대국을 재개한다.
- 부활한 AI의 2단계까지 승리해야 해당 스테이지의 최종 승리로 판정한다.
- 플레이어가 2단계에서 패배하면 일반 패배와 동일하게 즉시 런을 종료한다.

### 부활 전용 착수 처리 순서

```text
1단계 승리 판정
→ 최종 보상·노드 완료 보류
→ 종료 상태와 연속 패스 횟수 초기화
→ AI 부활 및 새 특성 추가
→ 새 특성의 전용 착수 1회
→ 포획·돌·유물 효과 처리
→ 플레이어 정상 턴
```

- 전용 착수는 AI의 일반 손패를 사용하지 않으며 기본 보충 드로우도 발생시키지 않는다.
- 전용 착수도 원칙적으로 합법 수·자충수·단순패·포획 규칙을 따른다. 규칙을 예외 처리하는 특성은 대국 전에 그 예외를 명시해야 한다.
- 전용 착수 후보가 없다면 전용 착수는 자동 패스로 처리하고 플레이어 턴으로 넘어간다.
