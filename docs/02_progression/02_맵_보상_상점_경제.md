# 맵·보상·상점·경제

## 1. 맵 구조

각 막은 갈림길이 있는 노드형 맵으로 구성한다. 플레이어는 다섯 개의 지도 노드를 거친 뒤 보스전에 진입한다.

```text
시작
→ 지도 노드 1
→ 지도 노드 2
→ 지도 노드 3
→ 지도 노드 4
→ 지도 노드 5
→ 보스
```

각 단계에서는 전투·상점·사건·도장·기원·정예 중 일부가 갈림길 후보로 제시된다. 따라서 한 막에서 치르는 일반 대국 수는 고정되지 않지만, 플레이어가 실제로 거치는 일반 전투 노드는 최소 1개, 최대 3개다.

지도 생성기는 모든 시작-보스 연결 경로에 일반 전투 노드가 1~3개 포함되도록 검증한다. 따라서 어떤 경로를 선택해도 다섯 노드 중 최소 2개는 비전투 노드가 된다. 보스전은 일반 전투 노드 수에 포함하지 않는다.

## 2. 노드 종류

| 노드 | 역할 | 주요 보상·기능 |
|---|---|---|
| 대국 | 일반 AI 상대 | 냥 + 3개 보상 중 1개 |
| 정예 | 강한 기풍 또는 변칙 규칙 | 유물 또는 희귀 돌 |
| 상점 | 경제와 덱 정리 | 구매, 제거, 부적 보충 |
| 사건 | 선택형 서사 | 위험과 보상의 교환 |
| 도장 | 덱 구성 조정 | 돌 제거, 교환 또는 복제 |
| 기원 | 돌 강화 | 돌 카드 1장 강화 |
| 보스 | 장 최종 상대 | 다음 장 진입 및 보스 보상 |

## 3. 일반 대국 보상

승리 시 다음을 제공한다.

1. 기본 냥
2. 상대 기풍 또는 성과에 따른 추가 냥
3. 세 개 후보 중 한 개의 보상 선택

보상 후보 유형:

- 돌 카드 영구 추가
- 보유 돌 카드 강화
- 부적 획득
- 낮은 확률의 유물
- 세 보상을 모두 거절하고 아무것도 받지 않기

## 4. 3개 보상 생성 규칙 초안

- 같은 이름의 보상은 한 화면에 중복 등장하지 않는다.
- 최소 1개는 현재 덱의 기풍과 연관된 후보로 제시한다.
- 최소 1개는 다른 기풍으로 확장할 수 있는 후보로 제시한다.
- 돌을 추가하지 않고 넘어갈 수 있다.
- 세 후보를 모두 거절하면 대체 보상이나 냥을 받지 않는다.
- 희귀도는 장과 정예 여부에 따라 가중치를 둔다.

## 5. 냥 경제 초안

화폐 명칭은 `냥`이다. 세계관에서는 고양이 울음소리에서 비롯된 명칭으로 설명한다.

| 항목 | 가격·보상 초안 |
|---|---:|
| 일반 대국 승리 | 35~50냥 |
| 정예 승리 | 60~90냥 |
| 일반 특수 돌 | 50~75냥 |
| 희귀 특수 돌 | 90~130냥 |
| 부적 | 25~45냥 |
| 일반 유물 | 120~160냥 |
| 첫 돌 제거 | 50냥 |

## 6. 상점

상점 기본 진열:

- 특수 돌 3개
- 부적 2개
- 유물 1개
- 돌 제거 1회
- 선택적으로 돌 강화 또는 새로고침

## 7. 돌 제거 가격

한 상점에서 돌 카드 제거는 최대 1회만 가능하다. 최소 덱 장수 제한은 없으며, 충분한 상점을 거치면 모든 영구 카드를 제거할 수 있다.

```text
제거 가격 = 50냥 + 이번 런의 이전 제거 횟수 × 25냥
```

덱이 0장이 된 경우 전투에서는 임시 일반석 카드가 생성되므로 착수 자체는 계속 가능하다.

## 8. 강화

강화는 단순 수치 증가보다 역할을 선명하게 한다.

예:

- 척후석: 덱 위 2장 확인 → 3장 확인
- 장군석: 포획 냥 +5 → +8
- 수호석: 활로 2 이하 조건 → 활로 3 이하 조건
- 희생석: 다음 턴 패 한도 +1 → 추가로 덱 위 1장 확인

같은 돌의 무한 강화는 허용하지 않고 기본적으로 1단계 강화만 둔다.

## 9. 경제 밸런스 목표

- 한 장에서 평균 1~2개의 주요 구매가 가능해야 한다.
- 모든 상점 상품을 살 수 없어야 한다.
- 포획형 냥 빌드가 승리 점수보다 포획만 추구하지 않도록 추가 냥에 대국당 상한을 둔다.
- 돌 제거가 항상 최적해가 되지 않도록 일반석 시너지와 빈 덱의 낮은 병종 다양성을 대가로 둔다.

## 10. 검토 필요

- 상점 새로고침 기능과 가격
- 2막 진입 전 상점 또는 무료 정비 제공 여부
- 한 런에서 등장하는 상점 수와 최대 제거 가능 횟수
