# 핵심 게임 루프

## 1. 전체 흐름

```text
런 시작
→ 시작 기풍 또는 기본 덱 선택
→ 대국
→ 냥 및 3개 보상 중 1개 획득
→ 다음 노드 선택
→ 덱·유물·부적 강화
→ 정예 및 보스 대국
→ 다음 장과 더 큰 바둑판 진입
→ 최종 19×19 대국
```

## 2. 한 번의 대국 루프

```text
턴 시작
→ 패 확인
→ 돌 카드 선택 또는 패스
→ 합법적 위치 선택
→ 착수 및 포획 판정
→ 돌·유물 효과 처리
→ 사용 카드 버림
→ 다음 카드 드로우
→ 상대 턴
```

## 3. 한 장의 진행 루프

| 단계 | 플레이어가 하는 판단 |
|---|---|
| 일반 대국 | 현재 빌드로 상대 기풍에 대응 |
| 보상 | 즉시 전력과 장기 시너지 중 선택 |
| 갈림길 | 위험, 성장, 경제 중 우선순위 선택 |
| 상점·도장 | 덱에 추가할 것과 제거할 것을 결정 |
| 정예 | 높은 위험을 감수하고 강한 유물 획득 |
| 보스 | 특수 규칙을 파악하고 장의 학습 내용을 종합 |

## 4. 장기 성장

런 밖의 영구 성장은 순수 능력치 증가보다 다음 방식이 적합하다.

- 새로운 돌 카드 해금
- 새로운 부적과 유물 해금
- 해금 전에는 등장하지 않던 콘텐츠를 이후 런의 보상·상점·사건 후보군에 추가
- 적 기사와 세계관 기록 해금
- 고난도 규칙과 도전 모드 해금

바둑 점수를 직접 올려주는 영구 강화는 실력과 런 밸런스를 훼손할 수 있으므로 지양한다.

## 5. 실패와 재도전

- 모드와 관계없이 대국에서 한 번 패배하면 즉시 런이 종료된다.
- 재대국권이나 부활권은 플레이어의 기본 기능으로 제공하지 않는다.
- 런 종료 후 사용한 기풍, 핵심 유물, 결정적 장면을 요약한다.
- 패배 원인을 단순 점수 차가 아니라 포획 손실, 연결 실패, 과도한 침투 등으로 보여준다.
