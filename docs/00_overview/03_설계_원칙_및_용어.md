# 설계 원칙 및 용어

## 1. 핵심 설계 원칙

### 바둑 우선

효과가 발동하지 않아도 모든 특수 돌은 정상적인 바둑돌로 착수할 수 있다.

### 직접 개입 최소화

판 위의 돌을 조건 없이 제거·이동·부활시키는 효과는 원칙적으로 사용하지 않는다.

AI 전용 패시브와 보스 기믹은 예외가 될 수 있다. 이 경우 발동 조건을 미리 공개하고 플레이어가 바둑판 위의 행동으로 대응할 수 있어야 한다.

### 기풍 유도

콘텐츠는 단순한 수치 강화가 아니라 특정한 바둑 행동을 시도하도록 유도한다.

### 예측 가능성

동시 발동 효과의 순서와 결과를 착수 전에 확인할 수 있어야 한다.

### 작은 판에서 학습

초반에는 활로와 포획, 중반에는 연결과 집, 후반에는 세력과 포석을 단계적으로 강조한다.

## 2. 공통 용어

| 용어 | 정의 |
|---|---|
| 돌 카드 | 이번 착수에 적용할 병종을 지정하는 덱 구성 요소 |
| 바둑돌 | 실제 바둑판에 놓인 흑돌 또는 백돌 |
| 병종 | 일반석·척후석·장군석처럼 돌에 부여된 특수 유형 |
| 덱 | 뽑기 더미, 패, 버림 더미를 포함하는 카드 집합 |
| 기풍 | 덱과 유물의 조합으로 형성되는 플레이 방식 |
| 그룹 | 가로·세로로 연결된 같은 색의 돌 집합 |
| 활로 | 그룹과 가로·세로로 인접한 빈 교차점 |
| 포획 | 활로가 없는 상대 그룹을 판에서 제거하는 처리 |
| 사석 | 의도적으로 희생하여 더 큰 이득을 얻는 돌 |
| 부적 | 대국 중 사용하는 일회성 보조 효과 |
| 유물 | 런 동안 지속되는 패시브 효과 |
| 대국 | 하나의 바둑 전투 |
| 장 | 특정 판 크기와 콘텐츠 묶음으로 이루어진 진행 구간 |
| 런 | 시작부터 패배 또는 최종 보스까지의 한 회차 |
| 면적 계가 | 자신의 돌과 자신의 돌로 둘러싸인 빈칸을 합산하는 방식 |
| 덤 | 선착의 이점을 보정하기 위해 후수에게 주는 점수 |

## 3. 콘텐츠 효과 작성 규칙

모든 효과 설명에는 다음 항목을 포함한다.

1. 발동 조건
2. 발동 시점
3. 효과 대상
4. 지속 시간
5. 중첩 여부
6. 한 턴 또는 한 대국의 발동 제한
7. 포획·패스·대국 종료 시 처리

## 4. 효과 문장 기준

좋은 예:

> 이 돌이 상대의 착수로 포획된 직후, 다음 플레이어 턴의 패 한도가 1 증가한다. 한 번의 착수로 여러 희생석이 잡히면 각각 발동한다.

피해야 할 예:

> 잡히면 드로우 보너스를 얻는다.

두 번째 문장은 자충수, 동시 포획, 지속 시간과 중첩 여부가 불명확하다.
